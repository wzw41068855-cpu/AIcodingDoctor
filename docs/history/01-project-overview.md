# AICodingDoctor项目

# 目标用户
帮助个人开发者快速理解陌生github代码仓库，并基于真实源码和日志提供可追溯的故障诊断建议。

# 技术栈

## AicodingDoctor v0.1 — 控制台版本需求

项目目标： 使用 LangChain 构建一个能够分析本地代码仓库和诊断常见报错的 AI 助手。
输入： 本地代码仓库路径、自然语言问题、报错信息。
输出： 代码解释、相关文件路径、代码引用、疑似故障原因及排查建议。
核心功能：
- 加载本地代码文件。
- 建立向量知识库。
- 基于 RAG 进行问答。
- Agent 自主调用代码检索工具。
- 支持多轮对话与基础记忆。
暂不实现： Web 页面、用户登录、数据库业务管理、GitHub API、自动代码修改和部署。
完成条件： 在控制台运行，能够对自己选择的真实 Python 项目完成代码问答与基本故障诊断。
